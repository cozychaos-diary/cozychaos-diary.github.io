{%- comment -%} Tiny line icon for a menu button. Used by nav.html, which passes name=home etc. `include.name` is the value passed in; each `when` draws one 24×24 icon. Line icons (home, heart, book, star, camera, mail) use stroke="currentColor", so they take the button's text colour. The two drawn icons (seal = wax seal with a gold butterfly, bow = burgundy lace bow) keep their own colours. Unknown or empty name → no icon at all. {%- endcomment -%} {%- case include.name -%} {%- when "seal" -%} {%- when "bow" -%} {%- when "home" -%} {%- when "heart" -%} {%- when "book" -%} {%- when "star" -%} {%- when "camera" -%} {%- when "mail" -%} {%- endcase -%}
